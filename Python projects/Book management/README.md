# 📚 Book Management & Search System

A console-based **Book Management System built with Python** that allows users to add, view, search, and delete books with persistent data storage using JSON.

This project was built to practice **Object-Oriented Programming (OOP), file handling, JSON, modules, CRUD operations, input validation, exception handling, and search logic** in Python.

---

## 🚀 Features

- ➕ Add new books
- 📖 View all books
- 🔍 Search books by:
  - Title
  - Author
  - Category
- 🔎 Partial and case-insensitive search
- 🗑️ Delete books
- 💾 Automatically save book data to JSON
- 📂 Load previously saved books when the application starts
- ⚠️ Input validation
- 🛡️ JSON error handling
- 🧱 Object-Oriented design
- 📦 Multiple Python modules

---

## 🛠️ Technologies Used

- **Python 3**
- **JSON**
- **OS module**
- **Object-Oriented Programming**
- **File Handling**

No external Python libraries are required.
