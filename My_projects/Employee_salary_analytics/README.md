# 👨‍💼 Employee Salary Analytics

A Python-based employee management and salary analytics application built using **Python, PostgreSQL, NumPy, and psycopg2**.

This project combines **CRUD operations, SQL analytics, Python data processing, and NumPy-based salary analysis** into a menu-driven command-line application.

---

## 📌 About the Project

**Employee Salary Analytics** is a command-line application that allows users to manage employee records and analyze salary-related data.

The application connects Python with PostgreSQL using `psycopg2` and uses NumPy for numerical salary calculations.

The main goal of this project is to demonstrate practical integration of:

- 🐍 Python
- 🗄️ PostgreSQL
- 🔗 Python–PostgreSQL integration
- 🔢 NumPy
- 📊 SQL aggregation and analytics
- 🛡️ Input validation
- 🔐 Environment variables
- 🧩 Modular Python functions

---

## 🚀 Features

### 👤 Employee Management

- ➕ Add multiple employees
- 👀 View all employees
- ✏️ Update employee salary
- 🗑️ Delete employees
- 🔎 Validate employee IDs
- ⚠️ Handle invalid user input
- 📭 Handle empty employee records

### 📊 Salary Analytics

The application provides:

- Average salary
- Total salary
- Highest-paid employee
- Lowest-paid employee

### 🏢 Department Analysis

Department-wise analytics include:

- Number of employees
- Average salary
- Maximum salary
- Minimum salary

Users can specify how many top employees they want to see based on salary.
